Run is not reproducible across runs, and this pair measures it again
-------------------------------------------------------------------
  Two runs were taken half an hour apart on this same commit, same SEED, TIME_SCALE and
  START_AT. A115 confirmed at simulated 10:22 and 10:27 — five simulated minutes apart — and the
  journal row counts differ with them: 16 decisions and 104 commands against 15 and 154. The
  earlier published runs confirmed at 10:16, 10:17, 10:19 and 10:23, so six runs on record now
  span 10:16 to 10:27.
  The sensor model draws once per Euler sub-step and the sub-step count follows real elapsed
  time, so host scheduling decides how many draws land inside a simulated minute.
  Teardown is at +313 s, ahead of the +336 s spurious A116A confirmation this profile documents,
  so that known R-3 false alarm is outside the captured window by design.
  The offline harness in evaluation/ is reproducible bit for bit, and that is where every
  requirement number comes from. This transcript is one draw of a demo, not evidence for a
  requirement.

What changed in the published evidence block since the last transcript
-----------------------------------------------------------------------
  Worth stating because it is the one place the demo's headline output moved. RUNBOOK section 4.4
  used to print a stuck-damper block whose third line was
      + stuck damper: the commanded step produced no matching response
  The current classifier prints, at the same moment, the negative of it:
      - stuck damper: NO COMMANDED STEP HAS BEEN JUDGED, so this diagnosis rests on localisation
        and flat fan power alone.
  The three-valued StepResponse separates "a step was judged and went unanswered" from "no step
  has been judged", and at confirmation no step has been judged, ever, because a probe is only
  requested once a case is latched. So the demo now confirms on two signals and says so. The
  sensor-drift line moved the same way, from an amplitude mismatch to "no commanded step has been
  judged yet". Nothing regressed: the leaf reaches the same classification, and the work order is
  honest about what it rests on.
